# Monday Coffee Data Analysis Using SQL
![](https://github.com/najirh/Monday-Coffee-Expansion-Project-P8/blob/main/1.png)

# Overview
This project analyzes coffee sales performance and market potential across multiple cities using SQL. I designed a relational database and performed advanced analysis to evaluate revenue trends, customer behavior, product performance, and city-level profitability. Using joins, CTEs, and window functions, I identified top-performing cities and products, sales growth patterns, and expansion opportunities, while comparing revenue against rent and customer metrics. The project demonstrates strong skills in SQL analytics, data modeling, and business decision support.

# Objective

* Analyze city-wise coffee sales performance to identify high-revenue markets
* Estimate coffee-consuming population across cities to assess demand potential
* Track monthly and quarterly revenue growth to understand seasonality and trends
* Compare revenue against rent and customer metrics to assess city-level profitability
* Identify top cities for business expansion using data-driven insights
* Demonstrate advanced SQL skills through joins, CTEs, and window functions
